# Duo Queue Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two players form a duo (site or Discord), always queue and play on the same team, and a sliding duo bonus scaled by how high the pair is rated both balances the teams and adjusts their rating; it all turns on with Season 1.

**Architecture:** Duos and invites live in two new tables behind a small DB module (`src/duos.ts`). The `Queue` learns to pop pairs whole, the `Matchmaker` keeps pairs together through join, leave, ready check failure, cancel and requeue, and passes pairs plus a per-player bonus to `balanceTeams`. `applyMatchRatings` reads the stored bonus from `match_players` so live rating and season recomputes agree. Routes, the Discord bot and the Play/Profile pages are thin callers of the matchmaker.

**Tech Stack:** TypeScript, Fastify, better-sqlite3, openskill, Preact, vitest (server project `tests/**`, web project `web/**` with happy-dom).

**Spec:** `docs/superpowers/specs/2026-10-21-duo-queue-design.md` (on master; Task 1 cherry-picks its commits onto this branch).

**Deviation from the spec:** spec section 6 lists a `matches.p_win_a_plain` column. Not added: `matchForecast` already rebuilds the plain chance from `rating_history`, and Task 6 adds `winProbAWithDuo` from the stored `duo_bonus`, so both numbers come from one source instead of a second stored copy.

## Global Constraints

- Everything is gated by `duoQueueLive(db)` = `seasonOneLive(db) && getSetting(db, 'duo_queue_enabled') !== '0'`. Off: no duo surfaces, the queue treats existing duos as solos, invites are refused.
- Duos are always on the same team (hard rule). No cap on duos per lobby or per team. No preference for splitting duos.
- No rating gap cap inside a duo.
- Bonus: `b = (min + (max - min) * pct) / 100` mu, `pct` = share of this season's `player_ratings` rows with mu below the pair's average mu. Settings `duo_bonus_min_sr` (default 50) and `duo_bonus_max_sr` (default 200), integers in SR points (100 SR = 1 mu).
- `b` is stored on `match_players.duo_bonus` at lobby completion and only ever read back from there.
- Rating: duo members from the all-duos-inflated run; solos on team A from the run inflating only team B's duos; solos on team B from the run inflating only team A's duos. No duos = today's single `rate()` call, unchanged.
- Invites expire after 10 minutes. One open invite per sender (a new one replaces the old).
- A duo lasts until a member ends it, or until a member is removed by staff (ban). Ending while queued leaves both queued as solos.
- Copy: player-facing text never mentions "mu"; it says "duo".

## Review Focus

1. **Pop with a duo straddling slot 8.** With a solo already behind the duo (after a restore or a requeue), the duo keeps its place and that solo fills slot 8 (Task 3). When a duo joins behind 7 solos there is nobody behind it: the pop goes now with the duo and the newest of the 7 solos stays at the front of the queue for the next pop (owner to confirm; Task 3 and Task 4 tests).
2. **Pop where greedy order comes up one short** (`[solo, duo, duo, duo, duo]`, 9 queued): must still pop exactly 8, never loop or pop 7. Test in Task 3.
3. **Partner blocked when the other presses Join** (partner timed out, unlinked Discord, in a match): join refuses with the partner named, nobody is queued. Test in Task 4.
4. **Kill switch flipped off while duos are queued**: the next pop treats them as solos, nothing throws, `state.duo` is null. Test in Task 4.
5. **Season recompute after the bonus settings change**: recompute uses the stored `duo_bonus`, so ratings come out identical. Test in Task 6.

```ts
import type { DB } from './db.js';
import { getSetting } from './settings.js';
import { seasonOneLive } from './seasonThemes.js';
import { inGoodStanding } from './standing.js';
import { getPlayer } from './players.js';

/**
 * Duo queue (docs/superpowers/specs/2026-10-21-duo-queue-design.md): two
 * players who always queue and play on the same team. Pure DB here; the
 * matchmaker owns what a duo means for the queue.
 */

/** How long an invite stays open. */
export const DUO_INVITE_MS = 10 * 60 * 1000;

/** Whether duos do anything: Season 1 has started (owner 2026-10-21: it
 *  ships with Season 1 exactly) and staff have not switched it off. */
export function duoQueueLive(db: DB): boolean {
  return seasonOneLive(db) && getSetting(db, 'duo_queue_enabled') !== '0';
}

export function partnerOf(db: DB, steamid: string): string | null {
  const row = db.prepare(
    'SELECT player_a, player_b FROM duos WHERE ended_at IS NULL AND (player_a = ? OR player_b = ?) LIMIT 1',
  ).get(steamid, steamid) as { player_a: string; player_b: string } | undefined;
  if (!row) return null;
  return row.player_a === steamid ? row.player_b : row.player_a;
}

export interface DuoInvite {
  id: number;
  fromId: string;
  toId: string;
  source: 'site' | 'discord';
  createdAt: string;
  resolvedAt: string | null;
  outcome: string | null;
}

export type DuoResult = { ok: true } | { ok: false; error: string };

const fail = (error: string) => ({ ok: false as const, error });

interface InviteRow { id: number; from_id: string; to_id: string; source: 'site' | 'discord'; created_at: string; resolved_at: string | null; outcome: string | null }

const toInvite = (r: InviteRow): DuoInvite => ({
  id: r.id, fromId: r.from_id, toId: r.to_id, source: r.source,
  createdAt: r.created_at, resolvedAt: r.resolved_at, outcome: r.outcome,
});

export function getDuoInvite(db: DB, id: number): DuoInvite | null {
  const r = db.prepare('SELECT * FROM duo_invites WHERE id = ?').get(id) as InviteRow | undefined;
  return r ? toInvite(r) : null;
}

function isOpen(inv: DuoInvite, now: Date): boolean {
  return inv.resolvedAt === null && now.getTime() - Date.parse(inv.createdAt) < DUO_INVITE_MS;
}

export function createDuoInvite(
  db: DB, fromId: string, toId: string, source: 'site' | 'discord', now = new Date(),
): { ok: true; inviteId: number } | { ok: false; error: string } {
  if (fromId === toId) return fail('you cannot duo with yourself');
  if (!getPlayer(db, toId) || !inGoodStanding(db, toId, now)) return fail('that player cannot queue');
  if (partnerOf(db, fromId)) return fail('you are already in a duo; end it first');
  if (partnerOf(db, toId)) return fail('that player is already in a duo');
  const at = now.toISOString();
  return db.transaction(() => {
    db.prepare("UPDATE duo_invites SET resolved_at = ?, outcome = 'replaced' WHERE from_id = ? AND resolved_at IS NULL")
      .run(at, fromId);
    const id = Number(db.prepare('INSERT INTO duo_invites (from_id, to_id, source, created_at) VALUES (?, ?, ?, ?)')
      .run(fromId, toId, source, at).lastInsertRowid);
    return { ok: true as const, inviteId: id };
  })();
}

export function acceptDuoInvite(db: DB, inviteId: number, steamid: string, now = new Date()): DuoResult {
  const inv = getDuoInvite(db, inviteId);
  if (!inv || inv.toId !== steamid || !isOpen(inv, now)) return fail('that invite is no longer open');
  if (partnerOf(db, inv.fromId) || partnerOf(db, inv.toId)) return fail('one of you is already in a duo');
  const at = now.toISOString();
  db.transaction(() => {
    db.prepare('INSERT INTO duos (player_a, player_b, created_at) VALUES (?, ?, ?)').run(inv.fromId, inv.toId, at);
    db.prepare("UPDATE duo_invites SET resolved_at = ?, outcome = 'accepted' WHERE id = ?").run(at, inviteId);
    // Every other open invite from or to either of them is moot now.
    db.prepare(
      `UPDATE duo_invites SET resolved_at = ?, outcome = 'void'
       WHERE resolved_at IS NULL AND (from_id IN (?, ?) OR to_id IN (?, ?))`,
    ).run(at, inv.fromId, inv.toId, inv.fromId, inv.toId);
  })();
  return { ok: true };
}

function resolveAs(
  db: DB, inviteId: number, steamid: string, who: 'fromId' | 'toId', outcome: 'declined' | 'cancelled', now: Date,
): DuoResult {
  const inv = getDuoInvite(db, inviteId);
  if (!inv || inv[who] !== steamid || !isOpen(inv, now)) return fail('that invite is no longer open');
  db.prepare('UPDATE duo_invites SET resolved_at = ?, outcome = ? WHERE id = ?').run(now.toISOString(), outcome, inviteId);
  return { ok: true };
}

export function declineDuoInvite(db: DB, inviteId: number, steamid: string, now = new Date()): DuoResult {
  return resolveAs(db, inviteId, steamid, 'toId', 'declined', now);
}

export function cancelDuoInvite(db: DB, inviteId: number, steamid: string, now = new Date()): DuoResult {
  return resolveAs(db, inviteId, steamid, 'fromId', 'cancelled', now);
}

/** `by` is the steamid that ended it, or 'system' (a ban). */
export function endDuo(db: DB, steamid: string, by: string, now = new Date()): DuoResult {
  const r = db.prepare(
    'UPDATE duos SET ended_at = ?, ended_by = ? WHERE ended_at IS NULL AND (player_a = ? OR player_b = ?)',
  ).run(now.toISOString(), by, steamid, steamid);
  return r.changes > 0 ? { ok: true } : fail('you are not in a duo');
}

export function openDuoInvites(db: DB, steamid: string, now = new Date()): { incoming: DuoInvite[]; outgoing: DuoInvite | null } {
  const rows = (db.prepare(
    'SELECT * FROM duo_invites WHERE resolved_at IS NULL AND (to_id = ? OR from_id = ?) ORDER BY id',
  ).all(steamid, steamid) as InviteRow[]).map(toInvite).filter((i) => isOpen(i, now));
  return {
    incoming: rows.filter((i) => i.toId === steamid),
    outgoing: rows.find((i) => i.fromId === steamid) ?? null,
  };
}

/** The duos present in `ids`, each once, in the order their first member appears. */
export function pairsAmong(ids: string[], partner: (id: string) => string | null): [string, string][] {
  const present = new Set(ids);
  const seen = new Set<string>();
  const out: [string, string][] = [];
  for (const id of ids) {
    if (seen.has(id)) continue;
    const p = partner(id);
    if (p && present.has(p) && !seen.has(p)) {
      out.push([id, p]);
      seen.add(id);
      seen.add(p);
    }
  }
  return out;
}
```

```ts
/**
 * How much stronger than their two ratings a duo counts, in mu, for balancing
 * and for rating (spec section 5). Slides from duo_bonus_min_sr for the
 * lowest-rated pairs to duo_bonus_max_sr for the highest, by the share of
 * this season's rated players below the pair's average mu. Hidden mu, not
 * display SR: SR is hidden through placement and the soft reset keeps the
 * order, so mu ranks a pair properly from Season 1's first day.
 */
export function duoBonusMu(db: DB, a: string, b: string): number {
  const season = currentSeasonId(db);
  const avg = (ensureRating(db, a, season).mu + ensureRating(db, b, season).mu) / 2;
  const row = db.prepare(
    'SELECT COUNT(*) AS n, SUM(CASE WHEN mu < ? THEN 1 ELSE 0 END) AS below FROM player_ratings WHERE season_id = ?',
  ).get(avg, season) as { n: number; below: number | null };
  const pct = row.n > 0 ? (row.below ?? 0) / row.n : 0.5;
  const min = settingNumber(db, 'duo_bonus_min_sr', 50, { min: 0, max: 1000, integer: true });
  const max = Math.max(min, settingNumber(db, 'duo_bonus_max_sr', 200, { min: 0, max: 1000, integer: true }));
  return (min + (max - min) * pct) / 100;
}
```

```ts
  /** A pop ends the stint even if its ready check later fails: a wait here
   *  is the wait until a ready check started.
   *
   *  With `partnerOf`, a duo whose two members are both queued is taken whole
   *  or not at all (src/duos.ts). A duo that does not fit keeps its place and
   *  the next solo behind it fills the slot. Always returns exactly `n` when
   *  at least `n` are queued. */
  takeBatch(n: number, partnerOf?: (id: string) => string | null): string[] {
    const taken: string[] = [];
    const skipped: [string, string][] = [];
    const done = new Set<string>();
    for (const id of this.order) {
      if (taken.length >= n) break;
      if (done.has(id)) continue;
      const p = partnerOf?.(id) ?? null;
      if (p && p !== id && this.order.includes(p)) {
        done.add(id);
        done.add(p);
        if (taken.length + 2 <= n) taken.push(id, p);
        else skipped.push([id, p]);
        continue;
      }
      done.add(id);
      taken.push(id);
    }
    // One short: only a duo is ever skipped, so one is waiting, and an odd
    // count holds at least one solo. Swap the last solo out for that duo.
    if (taken.length === n - 1 && skipped.length > 0) {
      for (let i = taken.length - 1; i >= 0; i--) {
        const p = partnerOf?.(taken[i]) ?? null;
        if (!p || !taken.includes(p)) {
          taken.splice(i, 1);
          taken.push(...skipped[0]);
          break;
        }
      }
    }
    const out = new Set(taken);
    this.order = this.order.filter((id) => !out.has(id));
    for (const id of taken) this.end(id, 'popped');
    return taken;
  }
```

```ts
   *  never jumps the line. One not queued counts as the back: it joins, and

  placePair(a: string, b: string): void {
    const ia = this.order.indexOf(a);
    const ib = this.order.indexOf(b);
    if (ia < 0 && ib < 0) return;
    if (ia >= 0 && ib >= 0) {
```

```ts
import type { FastifyInstance, FastifyRequest } from 'fastify';
import type { DB } from '../db.js';
import type { Matchmaker } from '../matchmaker.js';
import { makeRequireActive } from './guards.js';

/** Duo queue (docs/superpowers/specs/2026-10-21-duo-queue-design.md). Thin:
 *  every rule lives in the matchmaker, which also broadcasts the change. */
export interface DuoRouteOpts { db: DB; matchmaker: Matchmaker }

export async function duoRoutes(app: FastifyInstance, opts: DuoRouteOpts): Promise<void> {
  const { db, matchmaker } = opts;
  const requireActive = makeRequireActive(db);
  const inviteId = (req: FastifyRequest): number | null => {
    const n = Number((req.params as { id: string }).id);
    return Number.isInteger(n) && n > 0 ? n : null;
  };

  app.post('/api/duo/invite', async (req, reply) => {
    const me = requireActive(req, reply);
    if (!me) return;
    const to = (req.body as { steamid?: unknown } | undefined)?.steamid;
    if (typeof to !== 'string' || !/^\d{17}$/.test(to)) return reply.code(400).send({ error: 'steamid required' });
    const r = matchmaker.inviteDuo(me, to, 'site');
    if (!r.ok) return reply.code(409).send({ error: r.error });
    return { ok: true, inviteId: r.inviteId };
  });

  for (const action of ['accept', 'decline', 'cancel'] as const) {
    app.post(`/api/duo/invites/:id/${action}`, async (req, reply) => {
      const me = requireActive(req, reply);
      if (!me) return;
      const id = inviteId(req);
      if (id === null) return reply.code(400).send({ error: 'bad invite id' });
      const r = action === 'accept' ? matchmaker.acceptDuo(id, me)
        : action === 'decline' ? matchmaker.declineDuo(id, me)
          : matchmaker.cancelDuo(id, me);
      if (!r.ok) return reply.code(409).send({ error: r.error });
      return { ok: true };
    });
  }

  app.post('/api/duo/end', async (req, reply) => {
    const me = requireActive(req, reply);
    if (!me) return;
    const r = matchmaker.endDuo(me);
    if (!r.ok) return reply.code(409).send({ error: r.error });
    return { ok: true };
  });
}
```

```ts
import type { Matchmaker } from '../matchmaker.js';
import type { BotInteraction, InteractionReply } from './transport.js';

/** Accept / Decline on a /duo invite: dq:<inviteId>:a and dq:<inviteId>:d.
 *  Discord lets anyone press a button, so the presser is resolved to their
 *  linked player and must be the invitee. */
export const DUO_BUTTON_PREFIX = 'dq:';

const say = (content: string): InteractionReply => ({ ephemeral: true, payload: { content, embeds: [], components: [] } });

export async function handleDuoButton(
  deps: { db: DB; matchmaker: Matchmaker },
  i: Extract<BotInteraction, { kind: 'button' }>,
): Promise<InteractionReply> {
  const [, rawId, choice] = i.customId.split(':');
  const inviteId = Number(rawId);
  if (!Number.isInteger(inviteId) || (choice !== 'a' && choice !== 'd')) return say('That button no longer does anything.');
  const player = playerByDiscordId(deps.db, i.userId);
  if (!player || !inGoodStanding(deps.db, player.steamid)) return say('Link this Discord account to your Steam account on the site first.');
  const inv = getDuoInvite(deps.db, inviteId);
  if (inv && inv.toId !== player.steamid) return say('That invite is not for you.');
  const r = choice === 'a'
    ? deps.matchmaker.acceptDuo(inviteId, player.steamid)
    : deps.matchmaker.declineDuo(inviteId, player.steamid);
  if (!r.ok) return say(`Could not: ${r.error}.`);
  return say(choice === 'a'
    ? 'You are a duo now. Either of you joining the queue brings the other, and you always play on the same team.'
    : 'Declined.');
}
```

```ts
/**
 * Duo queue trial review (spec section 9). Read-only, on a COPY of the
 * production database:
 *
 *   cp pug.db /tmp/pug-copy.db && npx tsx scripts/duo-review.ts /tmp/pug-copy.db
 *
 * Run ~2 weeks after the Season 1 flip, then again at 40 duo matches (or 4
 * weeks, whichever is later). Baseline is Season 1 non-duo matches only.
 */
import { pathToFileURL } from 'node:url';
import { openDb, type DB } from '../src/db.js';
import { matchForecast } from '../src/rating.js';

export interface DuoMatchRow {
  duoTeam: 'a' | 'b' | 'both' | null;
  winner: 'a' | 'b' | 'draw';
  pPlain: number;
  pDuo: number | null;
  margin: number;
  forfeit: boolean;
  abandons: number;
  fourStack: boolean;
  band: 'low' | 'mid' | 'high' | null;
}

interface Bucket { matches: number; duoWinRate: number; predictedPlain: number; predictedWithBonus: number; meanMargin: number; forfeitRate: number; abandonRate: number }

const mean = (xs: number[]) => (xs.length ? xs.reduce((a, b) => a + b, 0) / xs.length : 0);

function bucket(rows: DuoMatchRow[]): Bucket {
  // The duo team's own view: its win, and its chance plain and with the bonus.
  // A match with a duo on both sides is counted from team A's side.
  const side = (r: DuoMatchRow) => (r.duoTeam === 'b' ? 'b' : 'a');
  const own = (p: number, r: DuoMatchRow) => (side(r) === 'a' ? p : 1 - p);
  return {
    matches: rows.length,
    duoWinRate: mean(rows.map((r) => (r.winner === side(r) ? 1 : 0))),
    predictedPlain: mean(rows.map((r) => own(r.pPlain, r))),
    predictedWithBonus: mean(rows.map((r) => own(r.pDuo ?? r.pPlain, r))),
    meanMargin: mean(rows.map((r) => r.margin)),
    forfeitRate: mean(rows.map((r) => (r.forfeit ? 1 : 0))),
    abandonRate: mean(rows.map((r) => (r.abandons > 0 ? 1 : 0))),
  };
}

export function summarizeDuoMatches(rows: DuoMatchRow[]) {
  const duo = rows.filter((r) => r.duoTeam !== null);
  return {
    duo: bucket(duo),
    solo: bucket(rows.filter((r) => r.duoTeam === null)),
    fourStack: bucket(duo.filter((r) => r.fourStack)),
    byBand: {
      low: bucket(duo.filter((r) => r.band === 'low')),
      mid: bucket(duo.filter((r) => r.band === 'mid')),
      high: bucket(duo.filter((r) => r.band === 'high')),
    },
  };
}

function load(db: DB, seasonId: number): DuoMatchRow[] {
  const minSr = Number((db.prepare("SELECT value FROM settings WHERE key = 'duo_bonus_min_sr'").get() as { value: string } | undefined)?.value ?? 50);
  const maxSr = Number((db.prepare("SELECT value FROM settings WHERE key = 'duo_bonus_max_sr'").get() as { value: string } | undefined)?.value ?? 200);
  const third = (maxSr - minSr) / 3;
  const matches = db.prepare(
    `SELECT id, winner, team_a_score, team_b_score, forfeit_why FROM matches
     WHERE season_id = ? AND state = 'completed' AND kind = 'pug' AND winner IS NOT NULL`,
  ).all(seasonId) as { id: number; winner: 'a' | 'b' | 'draw'; team_a_score: number; team_b_score: number; forfeit_why: string | null }[];
  const out: DuoMatchRow[] = [];
  for (const m of matches) {
    const f = matchForecast(db, m.id);
    if (!f) continue;
    const duos = db.prepare('SELECT team, duo_bonus FROM match_players WHERE match_id = ? AND duo_partner IS NOT NULL').all(m.id) as { team: 'a' | 'b'; duo_bonus: number }[];
    const teams = new Set(duos.map((d) => d.team));
    const duoTeam = teams.size === 0 ? null : teams.size === 2 ? 'both' : [...teams][0];
    const perTeam = (t: 'a' | 'b') => duos.filter((d) => d.team === t).length;
    const top = Math.max(0, ...duos.map((d) => d.duo_bonus * 100));
    out.push({
      duoTeam,
      winner: m.winner,
      pPlain: f.winProbA,
      pDuo: f.winProbAWithDuo,
      margin: Math.abs(m.team_a_score - m.team_b_score),
      forfeit: m.forfeit_why === 'gg',
      abandons: (db.prepare('SELECT COUNT(*) AS n FROM match_abandons WHERE match_id = ? AND restored_at IS NULL').get(m.id) as { n: number }).n,
      fourStack: perTeam('a') >= 4 || perTeam('b') >= 4,
      band: duos.length === 0 ? null : top < minSr + third ? 'low' : top < minSr + 2 * third ? 'mid' : 'high',
    });
  }
  return out;
}

function queueHealth(db: DB, sinceMs: number) {
  const duosOpen = (db.prepare('SELECT COUNT(*) AS n FROM duos WHERE ended_at IS NULL').get() as { n: number }).n;
  const formed = (db.prepare('SELECT COUNT(*) AS n FROM duos WHERE created_at >= ?').get(new Date(sinceMs).toISOString()) as { n: number }).n;
  const bySource = db.prepare("SELECT source, COUNT(*) AS n FROM duo_invites WHERE outcome = 'accepted' GROUP BY source").all();
  const lengths = db.prepare('SELECT AVG(julianday(ended_at) - julianday(created_at)) AS days FROM duos WHERE ended_at IS NOT NULL').get();
  const waits = db.prepare(
    `SELECT AVG(ended_at - joined_at) / 60000.0 AS minutes FROM queue_stints WHERE outcome = 'popped' AND requeued = 0 AND ended_at >= ?`,
  ).get(sinceMs);
  const readyFails = (db.prepare("SELECT COUNT(*) AS n FROM penalties WHERE kind = 'ready_fail' AND created_at >= ?").get(new Date(sinceMs).toISOString()) as { n: number }).n;
  return { duosOpen, formed, acceptedBySource: bySource, avgDuoLifeDays: lengths, avgPoppedWaitMinutes: waits, readyFails };
}
```

- [ ] **Step 4: Write `scripts/duo-calibrate.ts`**

```ts
/**
 * First values for duo_bonus_min_sr / duo_bonus_max_sr (spec section 8), on
 * a COPY of the production database:
 *
 *   cp pug.db /tmp/pug-copy.db && npx tsx scripts/duo-calibrate.ts /tmp/pug-copy.db
 *
 * 1. Pairs who already landed on the same team often (5+ completed PUGs)
 *    stand in for duos: find the bonus b (mu, both members) that makes their
 *    predicted win rate match their actual one, for the bottom half and the
 *    top quarter of such pairs by average mu.
 * 2. Forced-pair drift: replay each past 8-player lobby with a random pair
 *    forced together and report how far the best split moves from 50%.
 */
import { rating, predictWin } from 'openskill';
import { openDb } from '../src/db.js';
import { balanceTeams } from '../src/balance.js';

const path = process.argv[2];
if (!path || !path.includes('copy')) {
  console.error('usage: duo-calibrate.ts <path containing "copy">');
  process.exit(2);
}
const db = openDb(path);

type Hist = { match_id: number; player_id: string; team: 'a' | 'b'; mu: number; sigma: number; winner: 'a' | 'b' | 'draw' };
const hist = db.prepare(
  `SELECT rh.match_id, rh.player_id, mp.team, rh.mu_before AS mu, rh.sigma_before AS sigma, m.winner
   FROM rating_history rh
   JOIN match_players mp ON mp.match_id = rh.match_id AND mp.player_id = rh.player_id
   JOIN matches m ON m.id = rh.match_id
   WHERE m.state = 'completed' AND m.kind = 'pug' AND m.winner IN ('a','b')`,
).all() as Hist[];
const byMatch = new Map<number, Hist[]>();
for (const h of hist) byMatch.set(h.match_id, [...(byMatch.get(h.match_id) ?? []), h]);

// 1. Frequent same-team pairs.
const pairGames = new Map<string, { m: number; team: 'a' | 'b' }[]>();
for (const [m, rows] of byMatch) {
  for (const t of ['a', 'b'] as const) {
    const side = rows.filter((r) => r.team === t).map((r) => r.player_id).sort();
    for (let i = 0; i < side.length; i++) for (let j = i + 1; j < side.length; j++) {
      const k = `${side[i]}|${side[j]}`;
      pairGames.set(k, [...(pairGames.get(k) ?? []), { m, team: t }]);
    }
  }
}
const frequent = [...pairGames].filter(([, g]) => g.length >= 5);

function predictedWithBonus(pair: string[], m: number, team: 'a' | 'b', b: number): number {
  const rows = byMatch.get(m)!;
  const side = (t: 'a' | 'b') => rows.filter((r) => r.team === t)
    .map((r) => rating({ mu: r.mu + (t === team && pair.includes(r.player_id) ? b : 0), sigma: r.sigma }));
  const [pa] = predictWin([side('a'), side('b')]);
  return team === 'a' ? pa : 1 - pa;
}

function fitBonus(pairs: typeof frequent): number {
  const games = pairs.flatMap(([k, g]) => g.map((x) => ({ pair: k.split('|'), ...x })));
  const actual = games.filter((g) => byMatch.get(g.m)![0].winner === g.team).length / Math.max(1, games.length);
  let best = 0, bestErr = Infinity;
  for (let b = 0; b <= 5; b += 0.05) {
    const pred = games.reduce((n, g) => n + predictedWithBonus(g.pair, g.m, g.team, b), 0) / Math.max(1, games.length);
    if (Math.abs(pred - actual) < bestErr) { bestErr = Math.abs(pred - actual); best = b; }
  }
  return best;
}

const avgMu = ([k, g]: (typeof frequent)[number]) => {
  const [x, y] = k.split('|');
  const rows = byMatch.get(g[g.length - 1].m)!;
  return ((rows.find((r) => r.player_id === x)?.mu ?? 25) + (rows.find((r) => r.player_id === y)?.mu ?? 25)) / 2;
};
const sorted = [...frequent].sort((p, q) => avgMu(p) - avgMu(q));
const bottom = sorted.slice(0, Math.floor(sorted.length / 2));
const top = sorted.slice(Math.floor(sorted.length * 0.75));
console.log(`frequent pairs: ${frequent.length}`);
console.log(`fitted bonus, bottom half: ${(fitBonus(bottom) * 100).toFixed(0)} SR  -> proposed duo_bonus_min_sr`);
console.log(`fitted bonus, top quarter: ${(fitBonus(top) * 100).toFixed(0)} SR  -> proposed duo_bonus_max_sr`);

// 2. Forced-pair drift.
let seed = 1;
const rnd = () => ((seed = (seed * 1103515245 + 12345) % 2 ** 31) / 2 ** 31);
const drift: { free: number; forced: number }[] = [];
for (const rows of byMatch.values()) {
  if (rows.length !== 8) continue;
  const players = rows.map((r) => ({ steamid: r.player_id, mu: r.mu, sigma: r.sigma }));
  const i = Math.floor(rnd() * 8);
  let j = Math.floor(rnd() * 7);
  if (j >= i) j++;
  drift.push({
    free: Math.abs(balanceTeams(players).pWinA - 0.5),
    forced: Math.abs(balanceTeams(players, { groups: [[players[i].steamid, players[j].steamid]] }).pWinA - 0.5),
  });
}
const avg = (xs: number[]) => xs.reduce((a, b) => a + b, 0) / Math.max(1, xs.length);
console.log(`forced-pair drift over ${drift.length} lobbies: free ${(avg(drift.map((d) => d.free)) * 100).toFixed(2)} pts from 50%, forced ${(avg(drift.map((d) => d.forced)) * 100).toFixed(2)} pts`);
```
