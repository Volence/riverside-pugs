# In-game mod call (`/mod`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A silent in-game `/mod` command that pings the Discord moderation role in the admin channel with a context-rich card, files a ticket when a player is named, and lists every call on the admin site.

**Architecture:** pug-match emits a signed `PUGCALL` log line through `PugLog`. The web parses it in `logParse.ts`, stores it in `mod_calls` and files through `fileReport` when appropriate (`src/modCalls.ts`), then a `ModCallPoster` renders and posts or edits a Discord card with a Handling it button. A mod-guarded route and a People tab list the calls.

**Tech Stack:** TypeScript (Node, Fastify, better-sqlite3, vitest), Preact (web), SourcePawn 1.12 (compiled via wine with `plugin/build.sh`).

**Spec:** `docs/superpowers/specs/2026-09-24-mod-call-design.md` (Part 1 only; Part 2, SourceTV viewers, is a separate probe and NOT in this plan).

```ts
  // An in-game /mod call (src/modCalls.ts). Same treatment as PUGSAY: the
  // details text is LAST and every other field is read from the slice before
  // the first " text=", so nothing a player types can move the call onto
  // another account, another target or another match. Empty text is allowed:
  // most calls are just a reason and a name.
  if (body.startsWith('PUGCALL ')) {
    const at = body.indexOf(' text=');
    if (at < 0) return null;
    const head = kv(body.slice(0, at).split(/\s+/).slice(1));
    const text = body.slice(at + ' text='.length);
    const steamid = steamId64Of(head.steamid ?? '');
    if (!steamid) return null;
    const rawTarget = head.target ?? '';
    const target = rawTarget === 'team' || rawTarget === 'general' || rawTarget === 'none' ? rawTarget : steamId64Of(rawTarget);
    if (!target) return null;
    const reason = head.reason ?? '';
    if (!(MOD_CALL_REASONS as readonly string[]).includes(reason)) return null;
    const via = head.via;
    if (via !== 'game' && via !== 'tv') return null;
    const team = intOf(head.tteam);
    const match = intOf(head.match);
    const ord = intOf(head.ord);
    const half = intOf(head.half);
    const tms = intOf(head.tms);
    return {
      kind: 'call', steamid, target, reason: reason as ModCallReason, via, text,
      callerTeam: team !== null && team >= 0 && team <= 3 ? team : null,
      matchId: match !== null && match > 0 ? match : null,
      ordinal: ord !== null && ord >= 0 ? ord : null,
      half: half === 1 || half === 2 ? half : null,
      tMs: tms !== null && tms >= 0 ? tms : null,
    };
  }
```

Check `steamId64Of` returns `null`/empty for a non-SteamID string such as `bob` (it does for `123` in the PUGSAY tests); if it returns something truthy for arbitrary text, guard with `/^\d{17}$/` first.

### Task 3: Handle a call (store, file, fold, cap)

**Files:**
- Create: `src/modCalls.ts`
- Create: `tests/modCalls.test.ts`

**Interfaces:**
- Consumes: `LogEvent` `'call'` variant and `ModCallReason` (Task 1); `mod_calls`, settings, `FilingDeps.source` (Task 2); `fileReport` (`src/tickets/filing.ts`), `resolveAlias` (`src/aliases.ts`), `hasActiveBan` (`src/banState.ts`), `getPlayer` (`src/players.ts`), `getSetting` (`src/settings.ts`).
- Produces:
  ```ts
  export type ModCallEvent = Extract<LogEvent, { kind: 'call' }>;
  export const FOLD_WINDOW_MS = 5 * 60_000;
  export const RATE_CAP_PER_HOUR = 5;
  export interface ModCallRow {
    id: number; created_at: string; server_id: number | null; match_id: number | null; map: string | null;
    map_ordinal: number | null; half: number | null; t_ms: number | null; caller_steamid: string; caller_team: number | null;
    target_kind: 'player' | 'team' | 'general' | 'none'; target_steamid: string | null; reason: ModCallReason; text: string;
    via: 'game' | 'tv'; ticket_id: number | null; folded_into: number | null; pinged: number;
    post_state: 'pending' | 'posted' | 'skipped' | 'folded'; note: string; discord_message_id: string | null;
    handled_by_discord_id: string | null; handled_at: string | null;
  }
  export function handleModCall(db: DB, ev: ModCallEvent, serverId: number | null, deps: { adminSteamIds: string[]; map?: string | null; now?: Date }): ModCallRow;
  export function getModCall(db: DB, id: number): ModCallRow | undefined;
  export function foldedCalls(db: DB, parentId: number): ModCallRow[];
  export function onModCall(fn: (id: number) => void): () => void;   // subscribe; returns unsubscribe
  export const REASON_LABELS: Record<ModCallReason, string>;
  ```

`handleModCall` publishes the id of the row it stored to every `onModCall` listener AFTER the insert commits (for a folded call it publishes the new row's id; the poster resolves the parent).

Rules, in order:
1. `caller = resolveAlias(db, ev.steamid)`; `target` is `resolveAlias(db, ev.target)` when it is a SteamID. `target_kind` is `'player'` for a SteamID, else the literal. A `broke` call is always stored with `target_kind = 'none'` and `target_steamid = null`, whatever the line said.
2. Banned caller (`hasActiveBan(db, caller, now)`): store with `post_state = 'skipped'`, `pinged = 0`, `note = 'Caller is banned'`, no ticket, no fold. Publish.
3. Filing: when `target_kind = 'player'`, `reason !== 'broke'` and `getPlayer(db, caller)` exists, call `fileReport(db, caller, body, { adminSteamIds, now, source: 'game' })` where `category` maps `cheating|toxicity|griefing|afk` to themselves and `english|other` to `'other'`, and `text` is `ev.text` prefixed with `'Not speaking English: '` for `english` (trimmed, sliced to `MAX_TEXT`). Pass `matchId` and `moment` ONLY when the match exists and the target is on its roster (`SELECT 1 FROM match_players WHERE match_id = ? AND player_id = ?`); `moment` only when ordinal, half and tMs are all non-null. On success set `ticket_id`. On failure set `note = 'No ticket: ' + result.error`. Caller with no account: `note = 'No ticket: caller has no account'`. A `targetless` call gets no note.
4. Folding: find the newest row with `folded_into IS NULL`, `handled_at IS NULL`, `post_state IN ('pending','posted')`, `server_id IS ?` (the same server, `IS` so null matches null), `created_at > now - FOLD_WINDOW_MS`, and either the same `target_steamid` (both `player`) or both targetless (`target_kind != 'player'`). If found: `folded_into = parent.id`, `post_state = 'folded'`, `pinged = 0`.
5. Otherwise, `mod_calls_enabled = '0'`: `post_state = 'skipped'`, `note` appended `'Calls are turned off'`.
6. Otherwise, rate cap: count rows by this caller with `folded_into IS NULL` created in the past hour (before this one); if `>= RATE_CAP_PER_HOUR`, `pinged = 0` and `note` appended `'Not pinged: rate cap'`; else `pinged = 1`.
7. Insert inside a transaction, publish the id after it.

`REASON_LABELS`: `cheating: 'Cheating'`, `toxicity: 'Toxic / team fighting'`, `griefing: 'Griefing / throwing'`, `afk: 'AFK / no comms'`, `english: 'Not speaking English'`, `broke: 'Something broke'`, `other: 'Other'`.
